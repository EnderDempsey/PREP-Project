# PREP-Project

Unless otherwise stated, all code in this repository was done alone by Ender Dempsey. No generative AI was used in this project.

The data sets used in this project come from https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html.
In particular, this project uses the Portfolios Formed On Size [Daily] csv file.
In this project, I calculate the standard deviaions (using the population formula) of each decile for each year from 1927-2025.
Thus, there are 990 standard deviations outputted, organized by year and decile.

The standard deviations are outputted in a csv file called "StDevsForPortfoliosFormedOnSizeDaily"
